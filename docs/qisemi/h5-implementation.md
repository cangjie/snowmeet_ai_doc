- 商品关键词组合查询、顶级分类（含全部子分类）、仓库选择与默认勾选的“只看有库存”联动；总数、款式分页、各仓数量同步更新，详见 [筛选增强说明](inventory-filters-2026-10-20.md)，本次增强已于用户确认后部署至 `ai@99a6e306`，见 [本轮部署记录](deployment-filters-2026-10-20.md)；展开后保留全部尺码，按尺码与库存矩阵切换，查仓库、显示零仓、负库存标红、未知数量单列。
- 后续本机增强：现有搜索框支持商品与各级分类名称的部分词、多关键词组合；每条商品卡片展示完整分类路径，同款涉及多个分类则逐条展示，缺失上级有明确提示。本机真实页面已验证 `双板鞋 fisch 24-25 110 26.5`，返回 Fischer RC4 110、3 个尺码及三级分类。此项尚未部署，见 [本轮开发记录](keyword-category-search-2026-10-20.md)。
- 后续排序与二次筛选：搜索区下增加名称/顶级分类及正序/倒序选择；分类条列出当前主查询全部结果中的顶级分类和去重款数，可横向滚动，点击后二次筛选，保留“全部”及其余分类数量。主搜索条件变更清除二次选择，排序和分页保留选择，排序变更回第一页。此项本机开发，尚未部署，见 [说明](sorting-result-categories-2026-10-20.md)。
- 后续有货仓库条：分类条下再增加同样可横向滚动的仓库及括号款数；与结果分类交叉筛选，保留其他有货仓和数量。选仓后列表合计、全部尺码、矩阵与流水按该仓展示，切仓清理旧详情缓存。新主搜索/主仓/主分类/库存条件清除二次仓，排序和分页保留。此项尚未部署，见 [说明](result-warehouse-filter-2026-10-20.md)。
- 用户随后明确仓库括号应为商品件数：仓库条改用账面数量合计并加“件”，分类仍为去重款数并加“款”；汇总覆盖全部页及同款全部尺码，负库存参与抵扣，数量不完整显示“数量未知”。原仓库候选及二次筛选保持，详见 [数量修正](warehouse-quantity-labels-2026-10-20.md)。此项尚未部署。
- 点击尺码进入带 SKU/仓条件的流水，再追溯来源单据；商品档案可以定位到同款并默认选中该 SKU。
- 单据按关键词、业务日期、红冲筛选，档案按来源启停/删除筛选；来源状态、草稿、历史版本和缺档占位有单独标记。
- 单据详情包含基本资料及商品明细、分账、核销、关联、流水、历史、文件和完整原始字段分区；列表/详情分区分页，返回列表保留原筛选和页码。
- 图片通过受控文件引用接口取得 Blob 预览；其他文件下载。请求头随文件请求一起发送；不把会话值放进 URL，不链接上游签名地址。款式缩略图可取同款任一尺码主图，缺图不影响库存。后续本机修正为列表返回后自动加载、每页两个并发任务，无需点击展开，图片到达仅更新缩略图；新查询取消旧加载。缺图与读取失败分别占位，解码失败不显示破图。
- 后续默认排序明确为名称升序：不带排序参数进入、重新搜索或清空搜索时使用 `name/asc`；手动改排序后筛选和翻页仍保留，显式排序链接继续尊重其参数。本机当前页已回到名称升序。图片及默认排序修正尚未部署，见 [说明](list-photos-default-sort-2026-10-20.md)。
- 平台工作表表头、原始行和原文件分开查看；来源核对问题及逐模块采集状态可浏览。空模块显示本次快照暂无记录，保留入口。
- 账套选择、库存/全业务分别显示采集时间；两类批次分别固定。批次变化提示显式刷新；网络失败可重试。切换页面终止旧请求，迟到的响应不覆盖当前页面。
- 搜索/筛选栏在请求前就显示；中文输入不会因为即时请求而丢字。保留大整数身份字符串，所有来源文字及原始 JSON 做 HTML 转义。

## 会话预留

不做登录或权限判断。API 客户端可以从 `sessionStorage` 的 `SessionKey` / `SessionType` 读取预留值，统一放到同名请求头；缺省也能访问。后续接入正式员工登录时，应统一替换会话提供器及服务端过滤器，不为某一图片接口另造登录口径。
