## 文件保存

图片、单据附件，以及 12 份平台导出与 1 份收付款补充工作簿，按内容 SHA-256 去重后，共 **4,649 份、405,740,460 字节**，均已迁入项目既有 S3 私有存储：

```text
private/qisemi/datasets/<数据指纹>/media/files/...
private/qisemi/datasets/<数据指纹>/native/...
```

`qsm_file.storage_provider='s3'`、`object_key` 为私有对象键，`qsm_file_ref` 连接商品和单据。上传使用 Content-MD5，服务器逐对象核对长度及 SHA-256 元数据，失败数为 0。对实际文件在 S3 原站和图片域名的匿名访问均为 403，后续 H5 必须经员工鉴权读取，不能直接拼公开图片地址。

原始 JSONL 完整进入数据库；原始 SQLite 和 ZIP 是相同业务数据的重复载体，仍保留本机备份。本机原始数据、暂存、校验报告与短时授权都不进入 Git。放弃的私有磁盘传输副本已按任务指纹和文件哈希逐个清理，未清理其他服务器文件。

## 实施方式与剩余范围

原始 JSON 使用无损 gzip 物理列和可查询的 JSON 计算列；库存、单据等常用字段独立结构化。分批暂存与检查点控制日志，核对后在同一事务内更新单据指针、批次状态和来源两个当前指针；未发布批次不能作为业务查询数据。服务器从 S3 流式读压缩导入包，不落地巨大的暂存数据库。

七色米对象含索引实际占用约 **271.6 MB**；复核时数据库日志文件约 **6.1 MB**。服务器磁盘仍仅有约 300 MB 余量，后续定期同步前需另行处理容量；本次没有扩大清理其他应用或系统文件的范围。既有应用服务仍为 active，此项不是完整手机/业务流程验收。
