## 写请求及权限

- 有库存/检查/工具流程过账的接口全部携带 UUID requestId。同内容重试沿用 ID；网络结果未确认时拒绝换内容，提供“重试原请求”，防止重复过账。
- 待确认请求按门店和员工隔离保存在浏览器 localStorage，页面刷新仍可恢复；响应成功清记录，明确业务拒绝允许修改后新建 ID。不自动重复 POST。
- 入库草稿在当前页面实例内，刷新后消失；未确认过账请求与草稿分开保存。所有门店参数来自真实 GetMe，长单据 ID 保持字符串。
- 写入期间拦截重复点击和切页；失败保留表单。照片上传完成后才可提交。
- 店长维护与提前完成按钮按真实角色显示；最终权限仍由 API 检查。换算、保质期、批号、建议、出成率、份数及报表行只展示服务端结果。
- 检查提交先保存当前草稿，盘点过账先保存当前实盘；不把未保存输入留在客户端。历史提交后的原检查结果不可编辑。
